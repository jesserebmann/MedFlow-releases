# MedFlow Downloads

Publieke downloadlocatie voor de MedFlow Mac-app en ondertekende updateoverzichten.
De ontwikkelrepository wordt apart en prive beheerd.

## Beschikbaarheid

Er is nog geen installeerbare Mac-app in deze repository gepubliceerd.
Een broncoderelease is geen app-update. Download alleen appbestanden die expliciet
als Mac-build bij een release staan.

## Bijwerken

Een Mac-app met de ingebouwde updater controleert hier op een beschikbaar,
ondertekend app-archief. Klik in het MedFlow-startvenster op **Bijwerken**.
MedFlow stopt tijdelijk en start na installatie opnieuw op.
Rond opnames en bewerkingen af en sla openstaande tekst op voordat je bijwerkt.

Een oudere MedFlow.app zonder updater moet eenmalig worden vervangen door de
eerste app met updater. De app en de updater bevatten geen gebruikersdossiers.
De bestaande gegevensmap hoort niet verwijderd of vervangen te worden.

## Pilotondertekening

De pilotbuilds gebruiken Sparkle Ed25519-handtekeningen voor updatearchieven.
Zonder Apple Developer ID zijn deze builds niet door Apple genotariseerd.
De eerste installatie en een echte update moeten door de beheerder op een Mac
worden gecontroleerd voordat de app aan eindgebruikers wordt uitgedeeld.
